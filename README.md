# Crypto S/R Analyzer (Streamlit + Bybit)

Анализ криптопары в стиле S/R-зон: уровни поддержки/сопротивления, сценарии
ЛОНГ/ШОРТ с входом, целями и стопом. Данные — публичное API Bybit v5,
регистрация и ключи не нужны.

## Локальный запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Деплой на Streamlit Community Cloud (бесплатно)

1. Создайте репозиторий на GitHub и загрузите туда `app.py` и `requirements.txt`:
   ```bash
   git init && git add app.py requirements.txt README.md
   git commit -m "init"
   git remote add origin https://github.com/<you>/bybit-analyzer.git
   git push -u origin main
   ```
2. Зайдите на https://share.streamlit.io → **New app** → выберите репозиторий,
   ветку `main`, main file: `app.py` → **Deploy**.
3. Через пару минут сервис получит публичный URL вида
   `https://<you>-bybit-analyzer.streamlit.app`.

## Как строится анализ

- Уровни — фрактальные swing-high/swing-low, кластеризация в зоны
  с толерансом ~0.6·ATR(14).
- Ближайшие 3 зоны выше цены — сопротивления, ниже — поддержки
  (при нехватке зон достраиваются проекцией через ATR).
- **ЛОНГ**: пробой ближайшего сопротивления с закреплением, цели — следующие
  зоны, стоп — под ближайшей поддержкой.
- **ШОРТ**: отскок от ближайшего сопротивления, цели — зоны поддержки,
  стоп — над следующим сопротивлением.
- «Вероятности» — эвристика по EMA20/50, RSI(14) и импульсу за 20 свечей,
  это НЕ статистическая оценка.

## Дисклеймер

Не финансовый совет. Торговля криптовалютами связана с высоким риском.
